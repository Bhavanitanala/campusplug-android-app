# CampusPlug – Student Community Android App

CampusPlug is an Android-based micro-community platform designed for students to share academic resources, notes, assignments, and campus updates in a secure environment.

## Problem
Students often rely on multiple platforms to share notes and academic resources, making information scattered and difficult to access.

## Solution
CampusPlug provides a centralized community platform where students can securely share resources and updates within their campus.

## Technologies Used
- Kotlin
- Jetpack Compose
- Firebase Authentication
- Firebase Firestore
- Firebase Storage
- Android Studio

## Features
- Google Sign-In authentication
- Secure campus-based access
- Post sharing for notes and updates
- Real-time data storage using Firebase
- Media uploads including photos and documents

## How It Works
Students sign in using their Google account. After authentication, users can create posts, upload resources, and view updates shared by other students in the campus community.
